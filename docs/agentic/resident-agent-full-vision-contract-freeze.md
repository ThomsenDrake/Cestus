# Resident Agent Full-Vision CF-1 Contract Freeze

## Decision, Scope, And Dispatch Rule

This is the sole shared-contract decision for Waves 1–5 of the resident-agent
full-vision program. It consumes the approved Wave 0B plans (Tasks 109–116)
and resolves their pre-freeze proposals without granting production authority.
The governing sources are:

- `docs/superpowers/specs/2026-07-12-resident-agent-full-vision-program-design.md@c7dc10b9dd351fc76df083df8f2222252ba73d89`
- `docs/superpowers/plans/2026-07-12-resident-agent-full-vision-program-implementation.md@0b5726ec975bdc0aae97e540472ef3be4379b358`

CF-1 itself authorizes no production, provider, credential, Nous, browser,
tailnet, desktop, or live validation. A Wave 1–5 worker is non-dispatchable
until all of these facts exist in the append-only registry: a different fresh
reviewer approves this exact author commit; Relay A integrates that approved
commit; and the worker records the resulting full 40-character coordinator
integration SHA as `CF1-INTEGRATION-SHA` in its claim. The pre-freeze source
lock is `c996b197bde35aecff3be5120b654e7cc761f145`; it is evidence of the
complete Wave 0B input, never a substitute for `CF1-INTEGRATION-SHA`.

Only the Coordinator CF-1 contract task may add or version a shared event,
shared DTO, or shared capability row below. Later lanes may implement the
frozen rows but may not rename, widen, duplicate, or claim their ownership.
R is the only default runtime-factory writer. P is the only shared
provider-configuration writer. Existing gateway owners retain their own
approval/tool event lifecycles; no lane may replace them.

## Frozen Cockpit Command Vocabulary

Task141 alone owns `packages/local-runtime/test/agent-supervision-routes.test.ts`
with `packages/local-runtime/src/agent-supervision-routes.ts`,
`packages/ui/src/agent/ResidentSupervisionPanel.tsx`, and
`packages/ui/test/resident-supervision-panel.test.tsx`. The route accepts a
narrow versioned `SupportedResidentRuntimeCommandDto.v1` parser and receipt
only after the exact current snapshot and idempotency binding validate. It
accepts no extra key, authority override, provider setting, prompt, tool
argument, approval result, or compatibility widening. It must not invoke a
provider or tool, transfer bytes, send, approve, export, publish, escalate,
repair destructively, or mutate accepted graph state. Transport receipt means
requested or pending; durable state/readback is required for later effect
labels.

| Command code | Exact visible label | Required no-effect posture |
| --- | --- | --- |
| `workspace.recheck` | Recheck mounted workspace | Recheck mounted authority only; no fallback write. |
| `wake.pause` | Pause new wake claims | Request/record pause; never report already paused from transport alone. |
| `wake.resume` | Resume eligible wake processing | Request/record resume; never start a worker or provider. |
| `task.retry.request` | Queue retry | Queue a request only; no retry execution from the browser. |
| `task.cancel.request` | Request cancellation | Request cancellation only; no terminal/cancelled assertion without readback. |
| `provider.setup.open` | Open local provider setup | Open only an approved local P-owned platform flow; no secret browser input. |

The parser and panel reject the counterfactual labels `Run retry`, `Cancelled`,
and `Start the agent`; none aliases a frozen command. The Task141 RED and
GREEN command is the CF1-U-COMMAND command in this document, not an optional
route-test assignment. RED directly substitutes each of those three labels and
must fail the route/parser contract; GREEN proves all six exact label/code
pairs, the strict versioned DTO/parser, current snapshot, idempotency binding,
and no-effect posture without alias, fallback, or substitute command.

function candidateMatrix(candidate) {

  const candidateEnd = candidate.indexOf(matrixEnd);
  return candidateStart >= 0 && candidateEnd > candidateStart

  return candidateMatrix(candidate).split("\n").filter((line) => /^\| (CF1-|W[1-5]-)/.test(line));

const matrixHash = (candidate) => createHash("sha256").update(candidateMatrix(candidate)).digest("hex");

function validate(candidate, integrityHash = expectedHash) {
  const errors = [];
  const candidateRows = candidateRowsFor(candidate);
  if (matrixHash(candidate) !== integrityHash) errors.push("matrix integrity hash mismatch");
  if (candidateRows.length !== canonicalRows.length) errors.push("missing, duplicate, or additive governed row");

  const counts = new Map();
  for (const row of candidateRows) {
    const cells = rowCells(row);
    const id = cells[0] ?? "unknown";
    counts.set(id, (counts.get(id) ?? 0) + 1);
    if (cells.length !== 10 || cells.some((cell) => cell.length === 0)) errors.push(id + ": incomplete binding row");
    if (!canonicalIds.has(id)) errors.push(id + ": unknown or alias governed row");
  }
  for (const canonical of canonicalRows) {
    if (counts.get(canonical[0]) !== 1) errors.push(canonical[0] + ": missing or duplicate governed row");
  }
  for (let rowIndex = 0; rowIndex < canonicalRows.length; rowIndex += 1) {
    const expected = canonicalRows[rowIndex];
    const actual = candidateRows[rowIndex] ? rowCells(candidateRows[rowIndex]) : [];
    if (actual.length !== 10) {
      errors.push(expected[0] + ": absent or incomplete at canonical row position");
      continue;
    }
    for (let cellIndex = 0; cellIndex < 10; cellIndex += 1) {
      if (actual[cellIndex] !== expected[cellIndex]) errors.push(expected[0] + ": exact canonicalRows mismatch in governed cell " + (cellIndex + 1));
    }
  }

  if (!candidate.includes("R is the only default runtime-factory writer") || !candidate.includes("P is the only shared" + "\n" + "provider-configuration writer") || !candidate.includes("Only the Coordinator CF-1 contract task may add or version a shared event")) errors.push("exclusive shared-writer rule missing");
